# 我的个人主页

从零开始、用 Git 管理并托管到 GitHub 的第一个项目。纯 HTML + CSS，单文件，无任何依赖。

## 本地预览

直接双击 `index.html` 即可，或者在项目目录下起一个本地服务器：

```bash
python -m http.server 8000
```

然后浏览器打开 http://localhost:8000

## 文件说明

| 文件 | 作用 |
| --- | --- |
| `index.html` | 全部内容与样式，改动这一个文件就能改整站 |
| `.gitignore` | 告诉 Git 哪些文件不要纳入版本管理 |
| `README.md` | 就是本文件，别人点进仓库先看到它 |
